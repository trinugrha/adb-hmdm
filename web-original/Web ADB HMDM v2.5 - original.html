Uninstall Kaspersky

Uninstal aplikasi Kaspersky (com.kaspersky.kes) dari perangkat. Ikuti urutan langkah berikut agar uninstal tidak ditolak.

1

Hapus Data Kaspersky

Hubungkan perangkat, lalu klik tombol di bawah dan konfirmasi. Log akan menampilkan "Data Kaspersky berhasil dihapus."

2

Matikan Security / Aplikasi Admin Kaspersky di HP

Buka Pengaturan > Keamanan > Aplikasi admin perangkat (di beberapa merek: Keamanan & privasi > Lainnya), pilih Kaspersky, lalu Nonaktifkan. Jika tidak bisa dinonaktifkan, lepas perangkat dari konsol KES/MDM terlebih dahulu.

3

Uninstal Kaspersky

Klik tombol di bawah dan konfirmasi. Log akan menampilkan "Kaspersky berhasil di-uninstal."

Jika gagal

  • DELETE_FAILED_DEVICE_POLICY_MANAGER: Device Admin belum dimatikan. Ulangi Langkah 2.
  • DELETE_FAILED_USER_RESTRICTED / OWNER_BLOCKED: diblokir kebijakan Device Owner atau Profile Owner.
  • "Aplikasi tidak ditemukan": Kaspersky sudah tidak terpasang.
